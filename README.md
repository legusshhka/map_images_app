# Map Images App

Мобильное приложение на React Native + Expo: ставим маркеры на карте и прикрепляем к ним изображения из галереи.

## Стек

- React Native 0.88 / Expo SDK 58
- TypeScript
- Expo Router (файловая маршрутизация)
- react-native-maps (Google Maps на Android)
- expo-image-picker

## Установка и запуск

1. Установи Node.js (LTS) и приложение Expo Go на Android-устройство (или эмулятор Android Studio).
2. Установи зависимости:

   npm install

3. Запусти dev-сервер:

   npx expo start -c --android

4. Отсканируй QR-код в Expo Go или запусти на эмуляторе.

## Функциональность

- Карта на весь экран (react-native-maps)
- Добавление маркера долгим нажатием на карту
- Переход на экран деталей маркера по тапу
- Просмотр координат маркера
- Добавление изображений из галереи (мультивыбор)
- Удаление изображений с подтверждением
- Навигация «назад» к карте

## Принятые решения

- Состояние маркеров — React Context + useState (context/MarkersContext.tsx). Данные хранятся в памяти в рамках сессии. Это осознанный выбор: задание не требует персистентности, а Context даёт единый источник правды и чистые компоненты. При необходимости легко заменить на AsyncStorage.
- Доменные типы не зависят от библиотеки карт. В types.ts координата описана вручную ({ latitude, longitude }), чтобы модель данных не была привязана к react-native-maps.
- Компонентная структура соответствует заданию: Map, MarkerList, ImageList вынесены в components/, экраны — в app/.
- Обработка ошибок реализована для всех критичных сценариев:
  - отказ в разрешении на галерею;
  - отмена выбора изображения;
  - ошибка выбора изображения;
  - «маркер не найден» при переходе по некорректному id;
  - таймаут загрузки карты (8 с) с кнопкой «Повторить».

## Дополнительные функции

- Таймаут-детект незагрузившейся карты с fallback-экраном.
- Мультивыбор изображений за один заход в галерею.
- Подтверждение удаления изображения.
- Индикаторы загрузки при выборе изображений.
- SafeArea для нижней панели маркеров (Android).
- Горизонтальный список маркеров с координатами и счётчиком изображений.

## Известные ограничения

- Маркеры и изображения хранятся в памяти и теряются при перезапуске приложения (по условию задания персистентность не требовалась).
- Используется стандартный провайдер Google Maps; на некоторых версиях Expo Go / Android возможны проблемы с загрузкой карты. В этом случае предусмотрен fallback-экран с повторной попыткой.
- Публичные тайлы OpenStreetMap как альтернатива не используются, чтобы не нарушать политику OSM; при необходимости легко включить через UrlTile.
